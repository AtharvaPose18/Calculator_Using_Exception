## Description
A menu-driven Java calculator that performs basic arithmetic operations and demonstrates exception handling using try, catch, throw, and finally.

## Features
- Performs addition, subtraction, multiplication, and division.
- Accepts numbers from the user.
- Validates menu choices.
- Handles invalid numeric input.
- Handles division by zero.
- Allows the user to retry after errors.
- Provides an option to exit the calculator.

## Operations
1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Exit

## Concepts Used
- Java classes and methods
- Scanner for user input
- switch-case statements
- do-while loop
- Nested try-catch blocks
- InputMismatchException
- ArithmeticException
- throw keyword
- finally block
- continue statement

## How to Run
1. Install the Java Development Kit (JDK).
2. Save the program as ExceptionCalculator.java.
3. Open a terminal in the file's folder.
4. Compile the program:
   javac ExceptionCalculator.java

5. Run the program:
   java ExceptionCalculator
